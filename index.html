KidGuard

아이 노트북 사용 시간,
부모님 휴대폰으로 챙기세요.

KidGuard는 아이가 쓰는 Windows 노트북에 설치하는 무료 프로그램입니다. 하루 사용 시간을 정하고, 게임·사이트를 조절하고, 멀리 있어도 텔레그램으로 시간을 더 주거나 잠글 수 있습니다.

SHA-256 이 뭔가요?

받은 파일이 중간에 바뀌지 않았는지 확인하는 지문 같은 값입니다. 꼭 확인하지 않아도 설치할 수 있습니다. 확인하고 싶으면 다운로드 폴더에서 PowerShell 을 열고 Get-FileHash .\KidGuard-Setup.exe 를 입력해 위 글자와 같은지 보세요.

⏰ 하루 사용 시간

평일·주말 하루 몇 시간, 몇 시부터 몇 시까지 쓸지, 잠자는 시간을 정합니다. 끝나기 10·5·1분 전에 아이 화면에 알려 주고, 시간이 다 되면 화면이 잠깁니다.

🎮 앱마다 다르게

게임은 하루 1시간, 공부 앱은 시간에 넣지 않기, 어떤 앱은 아예 못 쓰게. 아이가 처음 보는 프로그램을 실행하면 바로 닫고 부모님께 허용할지 물어봅니다.

🌐 사이트 관리

성인·불법 웹툰 사이트는 기본으로 막고, 원하는 사이트를 더 막을 수 있습니다. 구글 안전 검색과 유튜브 제한 모드도 켤 수 있습니다. 어떤 사이트에 얼마나 머물렀는지 기록합니다.

📱 텔레그램으로 원격 설정

밖에서도 휴대폰 텔레그램으로 시간 더 주기, 지금 잠그기, 잠깐 풀어 주기를 할 수 있습니다. /settings 를 보내면 시간·앱·사이트를 화면에서 바꿀 수 있습니다.

📊 매일·매주 리포트

오늘 얼마나 썼는지, 많이 쓴 앱과 사이트, 밤늦게 쓴 일이나 막힌 앱을 여러 번 연 일 같은 '확인이 필요한 일'을 텔레그램으로 보내 드립니다.

🙋 아이와 대화하기 좋게

아이는 화면 오른쪽 아래 K 아이콘으로 남은 시간을 보고, 필요하면 버튼으로 시간을 더 달라고 요청합니다. 인터넷이 없을 때는 부모님이 알려 준 승인 코드로 연장합니다.

솔직히, 할 수 없는 것도 있어요

  • Windows 노트북·PC 전용입니다. 스마트폰, 태블릿, 맥은 관리하지 않습니다.
  • 사이트 필터는 크롬과 엣지만 됩니다 (안전 검색, 차단 사이트). 다른 브라우저(파이어폭스, 웨일 등)는 앱 관리에서 '사용 불가'로 막아 두세요.
  • 아이 계정이 관리자면 지킬 수 없습니다. 아이는 꼭 '표준' 계정으로 써야 합니다. 더 단단히 하려면 BIOS 비밀번호와 USB 부팅 막기를 권합니다.
  • 처음 보는 프로그램 확인은 실행 직후 닫는 방식이라, 아주 짧게 켜졌다 꺼지는 프로그램은 닫기 전에 끝날 수 있습니다 (기록과 알림은 남습니다).
  • 텔레그램 설정 화면은 버튼을 받은 순간의 값을 보여 줍니다. 오래 열어 두었으면 [🔄 최신 값 받기]를 눌러 주세요.
  • 새 버전이 나와도 저절로 알리지 않습니다 (노트북이 인터넷에서 버전을 확인하지 않게 했습니다). 업데이트는 이 페이지에서 새로 받아 설치합니다.
  • Windows 경고가 나옵니다. 비싼 코드 서명 인증서가 없어서 생기는 경고로, 아래 설치 2단계처럼 넘어가면 됩니다.
  • 아직 0.x 버전입니다. 여러 가정에서 써 보며 다듬는 중이라, 이상한 점이 있으면 알려 주세요.

준비할 것

  • 💻Windows 10 또는 11 노트북
    부모님이 쓰는 관리자 계정으로 설치합니다.
  • 🧒아이마다 Windows 계정 하나
    '표준 사용자' 계정이어야 합니다. 없으면 Windows 설정 → 계정 → 가족 및 다른 사용자에서 만듭니다.
  • 📲부모님 휴대폰의 텔레그램
    무료 메신저 앱입니다. 없어도 노트북에서는 쓸 수 있지만, 원격 설정과 알림을 받으려면 필요합니다.
  • ⏱20분쯤의 시간
    설치는 몇 분이면 끝나고, 처음 설정을 차근차근 따라 하면 됩니다.

처음 설정에서 하는 일

처음 설정 창이 하나씩 물어봅니다. 텔레그램은 건너뛰고 나중에 [텔레그램] 탭에서 해도 됩니다.

  1. 부모 비밀번호 정하기. 함께 나오는 복구 코드는 비밀번호를 잊었을 때 쓰니 종이에 적어 두세요.
  2. 아이 계정 고르기. 이 노트북의 계정 중 아이가 쓰는 것을 체크하고 부를 이름을 적습니다.
  3. 기본 규칙. 예: 평일 2시간, 주말 3시간, 밤 9시 30분 ~ 아침 7시는 잠자는 시간. 나중에 언제든 바꿀 수 있습니다.
  4. 텔레그램 봇 만들기. 텔레그램에서 @BotFather 를 찾아 /newbot → 봇 이름 → 사용자 이름(끝이 bot) 을 보내면 토큰이 옵니다. 그 토큰을 복사해 붙여 넣습니다. 이 봇은 우리 집만 쓰는 봇입니다.
  5. 휴대폰 등록. 화면의 QR 코드를 휴대폰 카메라로 찍거나, 봇에게 /register 123456 처럼 등록 코드를 보냅니다.
  6. 끝! 텔레그램에서 봇에게 /settings 를 보내 보세요.

아이 기록은 집 밖으로 나가지 않아요

💻 아이 노트북 ⇄ ✈️ 우리 가족 텔레그램 봇 ⇄ 📱 부모님 휴대폰
  • 사용 시간, 앱, 사이트 기록은 아이 노트북 안과 가족이 직접 만든 텔레그램 봇 대화에만 있습니다. 따로 회원 가입이나 KidGuard 서버가 없습니다. (텔레그램 메시지는 다른 텔레그램 대화처럼 텔레그램 서비스를 거쳐 오갑니다.)
  • 이 사이트와 텔레그램 설정 화면은 아무것도 받지 않습니다. 설정 화면은 글자와 버튼만 있는 파일이고, 값은 텔레그램을 통해서만 노트북과 오갑니다.
  • 노트북은 이 사이트나 GitHub 에 연결하지 않습니다. 그래서 새 버전 알림도 없습니다.
  • 사이트는 이름(예: youtube.com)만 기록하고, 주소·검색어·대화 내용·화면은 기록하지 않습니다.
  • 이 페이지는 쿠키, 방문 분석, 광고, 외부 글꼴을 쓰지 않습니다. (페이지를 올려 둔 GitHub 은 다른 웹사이트처럼 접속 기록을 남길 수 있습니다.)
  • '가족용 DNS' 를 켜면 사이트 이름 조회가 Cloudflare 또는 CleanBrowsing 의 가족용 서버로 갑니다 (성인 사이트를 막는 데 씁니다).

자주 묻는 질문

아이가 KidGuard 를 지우거나 끌 수 있나요?

아니요. 지우려면 부모 비밀번호(또는 복구 코드)가 필요하고, 표준 계정인 아이는 프로그램을 멈출 수 없습니다. 꺼지더라도 스스로 다시 켜지고, 시계를 바꾸거나 이름을 바꾼 게임을 여는 등 우회하려 하면 텔레그램으로 알려 드립니다.

노트북이 여러 대예요.

노트북마다 KidGuard 를 설치하고, 노트북마다 텔레그램 봇을 따로 만들어 주세요 (예: '첫째 노트북 봇', '둘째 노트북 봇'). 한 노트북에 아이 계정이 여럿이면 봇 하나로 모두 관리합니다.

업데이트는 어떻게 하나요?

이 페이지에서 새 설치 파일을 받아 똑같이 실행하고 [설치 / 업데이트] 를 누르면 됩니다. 설정과 사용 기록은 그대로 남습니다.

지우고 싶어요.

부모님 계정에서 시작 메뉴 → KidGuard 설치·제거 → [제거] → 부모 비밀번호(또는 복구 코드)를 입력합니다. 제거를 시작하고 끝낼 때 텔레그램으로 알려 드립니다.

부모 비밀번호를 잊었어요.

부모 관리 앱 로그인 화면의 [비밀번호를 잊었어요] 에서 텔레그램으로 재설정 코드를 받거나, 적어 둔 복구 코드를 입력합니다.

정말 무료인가요?

네. 광고도 유료 기능도 없습니다. 텔레그램 봇도 무료입니다.

문제가 생기면

문제가 있으면 부모 관리 앱 [설정] → [진단 파일 저장]으로 만든 파일을 이 프로그램을 알려 준 분께 보내 주세요.

진단 파일에는 텔레그램 토큰과 비밀번호가 들어가지 않습니다.
